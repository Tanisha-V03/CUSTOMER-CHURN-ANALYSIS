# Customer Churn Analysis

## Project Overview

Customer Churn Analysis is an end-to-end data analytics project focused on understanding customer behavior and identifying factors that contribute to customer churn.

The project uses **Excel, Python, SQL, and Power BI** to perform data exploration, data cleaning, analysis, and visualization. The final insights are presented through an interactive Power BI dashboard to help understand churn patterns and customer characteristics.

## Objectives

* Analyze customer churn and retention patterns
* Identify factors associated with customer churn
* Explore customer demographics and service-related information
* Analyze customer tenure, contract type, payment methods, and other relevant attributes
* Perform data exploration and cleaning
* Use SQL to extract meaningful business insights
* Build an interactive Power BI dashboard
* Present key findings through clear KPIs and visualizations

## Tools & Technologies

* **Microsoft Excel** – Data exploration, initial analysis, filtering, and understanding the dataset
* **Python** – Data cleaning, preprocessing, exploratory data analysis, and visualization
* **SQL** – Data querying, aggregation, filtering, and business analysis
* **Power BI** – Interactive dashboard development, KPIs, charts, and data visualization

## Project Workflow

### 1. Data Exploration using Excel

Excel was used during the initial stage of the project to explore and understand the dataset.

Activities included:

* Reviewing the dataset structure
* Checking columns and data types
* Exploring customer and churn-related information
* Filtering and sorting data
* Identifying missing or inconsistent values
* Performing basic calculations and observations

### 2. Data Cleaning & Analysis using Python

Python was used to prepare the dataset for further analysis.

Key activities included:

* Importing the dataset using Pandas
* Checking missing values
* Identifying duplicate records
* Cleaning and transforming data
* Converting data types where required
* Performing exploratory data analysis
* Analyzing churn patterns using Pandas and visualization libraries

### 3. SQL Analysis

SQL was used to perform structured analysis and extract business insights from the cleaned data.

The analysis included:

* Filtering customer records
* Grouping customers based on different attributes
* Calculating churn counts and percentages
* Analyzing customer segments
* Comparing churn across different customer categories
* Performing aggregate calculations
* Writing business-oriented SQL queries

### 4. Power BI Dashboard

Power BI was used to create an interactive dashboard for presenting the analysis.

The dashboard includes:

* Total Customers
* Churned Customers
* Churn Rate
* Retained Customers
* Customer segmentation
* Churn analysis by different customer attributes
* Interactive filters and slicers
* Charts and visualizations for better understanding of churn patterns

## Key Analysis Areas

The project explores customer churn based on factors such as:

* Customer demographics
* Customer tenure
* Contract type
* Payment method
* Services used
* Monthly charges
* Total charges
* Customer status
* Other relevant customer attributes

## Dashboard

The Power BI dashboard provides an interactive view of customer churn and allows users to explore different customer segments using filters and slicers.

It includes key performance indicators (KPIs), visualizations, and filters to explore churn patterns and understand the factors associated with customer churn.
